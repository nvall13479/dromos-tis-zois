# 791. Περί τού ότι ο δούλος δεν μπορεί να δίνει παραγγελία (παράθεση) στον κύριό του

Ερώτηση

Άλλος επίσκοπος έστειλε να παρακαλέσει τον ίδιο Γέροντα Βαρσανούφιο να τού δώσει παραγγελία.

Απόκριση

Τί να πω στη θεοφιλία σας; Να πω ότι δεν είναι δυνατό στο δούλο να δώσει παραγγελία στον κύριό του, αλλ' ακόμα δεν απαλλάχθηκα από την κενοδοξία μου, να θεωρώ τον εαυτό μου ότι είναι δούλος όλων. Απορώ λοιπόν μη βρίσκοντας απολογία· βρίσκω μόνο να καταφύγω σ' αυτό· 'Συγχώρεσέ με στο όνομα τού Κυρίου και προσευχήσου για μένα, ώστε να μη κατακριθώ στη δική σας παρουσία, να κατανοήσω ότι υπάρχει Θεός, και να φροντίσω τις θείες εντολές του, ώστε να ελεηθώ.
