# 365. Περί τού πόσες φορές πρέπει να προσεύχεται κανείς για τον λογισμό που τον απασχολεί

Ερώτηση

Δεσπότα μου, πόσες φορές πρέπει να προσεύχομαι, για να πληροφορηθεί ο λογισμός γι’ αυτό.

Απόκριση

Όταν δεν μπορείς να ερωτήσεις τον γέροντα, πρέπει να προσεύχεσαι τρεις φορές για κάθε πράγμα· και μετά από αυτό να δεις προς τα πού ρέπει η καρδιά, έστω και μία τρίχα, και αυτό να κάνεις. Διότι είναι φανερή η πληροφορία, και οπωσδήποτε φαίνεται στην καρδιά.
